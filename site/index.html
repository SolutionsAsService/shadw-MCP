One server, the API the CLI already uses

shadw-MCP sends the same requests as Dylan Wong's shadw CLI: a bearer API key, an optional x-hive-team header, and the same routes (mostly /v1) on the Shadw control plane (default https://api.shadw.cloud). src/client.js:40

The key decides what the agent may do

The server never deletes a project or a deployment. Revoking a key is the only destructive tool, and it is marked destructiveHint. Whether a key may create another key, and with which role, is decided by the Shadw server, not by this one.
