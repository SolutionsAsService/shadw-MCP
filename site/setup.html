0 · Set up

One key, three commands, and your agent can reach Shadw.

  1. Make a key

    In the Shadw dashboard, open Settings → API Keys. Use role member to deploy, or viewer for read-only checks. An agent that already has a key can create one with shadw_create_api_key; see Keys.

  2. Install

    git clone https://github.com/SolutionsAsService/shadw-MCP
cd shadw-MCP/server && npm install

  3. Register it

    Claude Code:

    claude mcp add shadw -e SHADW_API_KEY=shadw_your_key -- node /path/to/shadw-MCP/server/src/cli.js

    Any other MCP client:

    {
  "mcpServers": {
    "shadw": {
      "command": "node",
      "args": ["/path/to/shadw-MCP/server/src/cli.js"],
      "env": { "SHADW_API_KEY": "shadw_your_key" }
    }
  }
}

VariableMeaningDefault
SHADW_API_KEY, SHADW_TOKENBearer API keynone
SHADW_API_URL, SHADW_APIControl-plane base URLhttps://api.shadw.cloud
SHADW_TEAMTeam slug, sent as x-hive-teamnone: the key's own team

Without a key the server still starts, and says so on stderr; only shadw_platform_status works. server/src/cli.js:6
